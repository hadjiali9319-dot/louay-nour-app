# عالم لؤي ونور الهدى

مشروع HTML مُغلّف كتطبيق Android باستخدام Capacitor.

## بناء APK عبر GitHub من الهاتف

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع جميع محتويات هذا المجلد إلى المستودع، مع إظهار الملفات المخفية كي لا يسقط مجلد `.github`.
3. افتح تبويب Actions.
4. اختر `Build Louay and Nour APK`.
5. اضغط `Run workflow`.
6. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل Artifact باسم `louay-nour-learning-apk`.
7. فك ضغط ملف Artifact لتحصل على `app-debug.apk` وثبّته على هاتف Android.

هذه نسخة Debug قابلة للتثبيت والتجربة، وليست نسخة متجر Google Play موقّعة للنشر.
